# 职教智能体

面向职业教育高水平专业群建设的教学实训与岗位技能智能体开发项目。

## 项目结构

```
职教智能体/
├── docs/                       # 项目文档与比赛方案
│   ├── 比赛方案.pdf            # 科大讯飞智能体开发比赛方案
│   ├── 完整技术文档.md         # 项目技术文档
│   ├── 具体工作任务.md         # 工作任务分解
│   └── 目标重定位.docx         # 项目目标重定位
├── references/                 # 参考标准与政策文件
│   ├── 高职教学标准.pdf
│   ├── 人培方案.pdf
│   ├── 工业机器人操作与运维职业技能标准_V2.0.docx
│   └── 信息.docx
├── 工业机器人系统运维员/       # 工业机器人岗位分析
│   ├── 招聘信息与能力图谱_完整版.md
│   ├── 招聘爬取结果.md
│   ├── 招聘数据展示平台.html
│   └── 招聘汇总.md
├── 数控操作工/                 # 数控操作工岗位分析
│   ├── 岗位能力.md
│   ├── 招聘数据.json
│   ├── 企业侧工作任务与能力深度调研报告.md
│   ├── 企业工作任务精细分解_教学规划用.md
│   ├── 一线工人真实声音_论坛调研汇编.md
│   ├── 技术讨论帖子溯源_论坛原帖与URL汇总.md
│   ├── 完整数据展示平台.html
│   ├── 招聘数据展示平台.html
│   └── mohrss_raw.csv
├── 招聘数据处理/               # 招聘数据清洗与分析
│   ├── new_招聘.md
│   └── 去重.md
├── scripts/                    # 工具脚本
│   ├── convert.js
│   └── dedup.js
└── 岗位能力生成/               # Django 应用（岗位能力图谱生成系统）
    ├── manage.py
    ├── config/                 # Django 配置
    ├── ability/                # 能力图谱模块
    ├── accounts/               # 用户账户模块
    ├── chain/                  # 能力链模块
    ├── crawl/                  # 爬虫模块
    ├── frontend/               # 前端页面
    ├── data/                   # 数据文件
    └── output/                 # 输出结果
```

## 技术栈

- **后端**: Django (Python)
- **前端**: HTML/CSS/JS
- **AI能力**: 星火大模型 API

## 快速开始

```bash
cd 岗位能力生成
pip install -r requirements.txt
python manage.py runserver
```
